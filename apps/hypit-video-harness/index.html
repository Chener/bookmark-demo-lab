    原帖点名的两件头疼事

    抽卡黑盒

    改一个字，整条重抽

    视频模型只吐一段写死的 MP4。Harness 把工作流落成可编译脚本，只重生变化的那一层。

    手搓剪映

    时间码不是给 Agent 用的

    人手拖图层没问题；让 Coding Agent 去对帧号就卡住。词锚定的语言才能当编译目标。

    一条工作流

    同一结构，换角色再出

    榜单、播客、街头采访都能当模板：换主持、换产品、换语言，结构留下。
